# プロダクト概要

Mizuyari は、市販の安価な目覚まし時計（ダイソー製）のアラーム信号をトリガとして、
ポンプ／モータを一定時間だけ駆動し植物への自動水やりを行うハードウェアプロジェクト。

電気回路CAD（KiCad）とマイコンファームウェアを同一リポジトリで管理するモノレポとして運用する。

## コア能力

- **アラーム信号の取り込み**: 時計側のアラーム出力（`ALM` ネット）を入力トリガとして扱う
- **給水時間のワンショット生成**: NE555 による単安定／時定数回路で給水時間を決定し、可変抵抗で現場調整する
- **負荷駆動**: 小信号トランジスタ + N-ch MOSFET の 2 段構成でモータ／ポンプを駆動し、還流ダイオードで誘導性負荷を保護する
- **状態表示と手動操作**: LED による動作表示とプッシュスイッチによる手動給水
- **回路検証**: 実装前に ngspice（KiCad 内蔵シミュレータ）で過渡解析を行い、時定数と駆動波形を確認する

## 主なユースケース

- 留守中・不在時の鉢植えへの定時給水
- 既製品の時計を改造せず、アラーム信号だけを借用する低コストな自動化
- アナログ回路（555 + ディスクリート）のみで完結する構成と、将来のマイコン制御版との比較検討

## 価値

- 入手性の高い部品のみで構成し、専用タイマIC やクラウド連携を必要としない
- 時計側のアラーム設定 UI をそのまま給水スケジュールの UI として流用できる
- スルーホール部品中心のため、手はんだでの再現・改造が容易
